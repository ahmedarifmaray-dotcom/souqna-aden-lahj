# سوقنا | SOUQNA — النسخة التجريبية الأولى

## محتويات المشروع
- `index.html` : هيكل صفحات الموقع.
- `style.css` : التصميم والألوان والتجاوب مع الهاتف.
- `app.js` : البحث والتصفية حسب المدينة والقسم وبيانات البطاقات.

## تشغيل الموقع على الهاتف
1. فك ضغط ملف ZIP باستخدام تطبيق إدارة الملفات.
2. افتح `index.html` في متصفح الهاتف لمعاينة الموقع محلياً.
3. إذا لم يعمل فتح الملفات محلياً بصورة صحيحة، انشر الملفات على استضافة صفحات ثابتة مثل GitHub Pages.

## تنبيه مهم
كل أسماء المحلات في `app.js` تجريبية وليست محلات حقيقية. لا تنشرها باعتبارها بيانات حقيقية.
لا تضف أرقام هواتف أو صوراً أو عروضاً إلا بعد الحصول على موافقة أصحابها والتحقق من صحة المعلومات.

## إعداد واتساب
افتح `app.js` وابحث عن:
`const WHATSAPP_NUMBER = "";`
ضع رقم واتساب مخصصاً للمشروع بصيغة دولية من دون + أو مسافات، بعد التأكد من إمكانية استخدامه.

## تعديل بيانات المحلات
داخل `app.js` ابحث عن المصفوفة `listings`.
استبدل البيانات التجريبية باسم المحل والمدينة والمنطقة والقسم والوصف بعد موافقة المحل.
القيم المتاحة للأقسام حالياً: `ملابس` و`هواتف` و`عطور` و`مطاعم` و`منزل`.

## حدود النسخة الحالية
هذه نسخة واجهة أمامية تجريبية. لا يوجد تسجيل تجار، أو قاعدة بيانات، أو لوحة إدارة، أو استقبال طلبات وحفظها، أو دفع إلكتروني. ستحتاج هذه الخصائص إلى backend وقاعدة بيانات وخطة أمان وخصوصية قبل إطلاقها كمنصة تجارية كاملة.
